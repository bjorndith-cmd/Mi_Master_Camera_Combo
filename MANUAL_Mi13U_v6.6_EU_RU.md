# Мануал: Master Camera Combo v6.6 EU
### Xiaomi 13 Ultra (ishtar) · xiaomi.eu · HyperOS 3 / Android 16

Файл модуля: `Mi13U_Master_Camera_Combo_5_v6.6_EU_LocalAI_by_borndead.zip`  
Репозиторий проекта: `https://github.com/bjorndith-cmd/Mi_Master_Camera_Combo`

> В этом мануале настройки называются так, как они подписаны в камере. Латинские имена в скобках — технические ключи (`pref_*`), по ним можно искать в логах. Номера пунктов меню не используются: нумерация меняется между сборками.

---

## 1. Что внутри модуля

| Слой | Что это | Зачем |
|---|---|---|
| **Payload** | MiuiCamera **Universal 5.0 Beta 8.3** (versionCode 599830000) + 55 библиотек | сама камера, проверенная на xiaomi.eu A16 |
| **Фиче-слой 6.8** | свойства + конфиги: SAT-зум видео, конверт 50 Мп, MIVI-контракт, диафрагма, портрет, Leica-пресеты | функции, которые в 5.0-payload сами не включались |
| **device_features** | аддитивный `zzz_borndead_camera.xml`, **204 ключа** (пак 5.0 + пак 6.8) | флаги режимов: 8K, 4K120, Dolby, Street, Director, Super Moon, Super Macro, зум-кнопки. Стоковый `ishtar.xml` не заменяется |
| **Права** | privapp-allowlist на 42 разрешения | чтобы вкладки «Улучшения»/«Бьютификация» реально включались |
| **ИИ-пак v6.6** | AISP + AINR + CyberFocus + MIVI SR + AI-сцена/коуч/режиссёр + ИИ-редактор галереи | всё считается **на устройстве** (NPU/DSP), облако выключено |
| **Логи** | `/sdcard/Download/CameraMod_Logs` | диагностика: что реально происходит в камере |

## 2. Установка, обновление, откат

1. Снести прежние модули камеры (в том числе старые версии этого) → **перезагрузка**.
2. Magisk/KernelSU → Модули → «Установить из хранилища» → выбрать ZIP.
3. В логе установки: баннер `Master Camera Combo v6.6 EU` и `Payload: MiuiCamera Universal 5.0 Beta 8.3`.
4. **Перезагрузка обязательна.**
5. Проверка: Magisk → модуль → **Action → 1) Status**.

Ожидаемо в статусе:
```
Build       : v6.6-EU-A16 (5.0 Beta 8.3 + 6.8 layer + LOCAL AI)
Camera ver  : versionName=Universal 5.0 Beta 8.3
MIVI cache  : PRESENT
LOCAL AI    : ON (AISP/AINR/CyberFocus/SR, default)
Size env    : ON (50 MP envelope, default)
AISP/ASD    : ON (Leica render, default)
```

Откат, если камера не понравилась:
- Action → **5) Disable module now** → перезагрузка (вернётся стоковая камера);
- или файл-флаг `/sdcard/disable_camera` → перезагрузка;
- аварийно модуль сам отключится после 2 неудачных загрузок (bootloop saver).

## 3. Меню Action: что делает каждый пункт

| Пункт | Действие |
|---|---|
| 1) Status | вся сводка: сборка, версия камеры, состояние MIVI-кэша, ИИ, тумблеров, SELinux |
| 2) Re-inject MIVI info | заново кладёт контракт MIVI в кэш камеры (лечит «мелкие фото» без перезагрузки) |
| 3) Toggle strict priv-app perms | строгий/логирующий режим привилегированных разрешений (по умолчанию логирующий) |
| 4) Enable module now | снимает флаги отключения |
| 5) Disable module now | выключает оверлей камеры (возврат стока после перезагрузки) |
| 6) Collect SELinux denials | 20 с собирает `avc: denied` в `avc_denial.txt` |
| 7) Manual reset | сброс счётчиков и флагов |
| 8) Toggle AISP/ASD | **Leica-рендер ↔ быстро и нейтрально**. Если фото уходят в синеву или тормозят — переключить в OFF |
| 9) Toggle 50 MP envelope | вкл/выкл конверт размеров (лечение «1.6 Мп») |
| 10) Toggle LOCAL AI pack | **весь ИИ-пак v6.6**: AISP + AINR + CyberFocus + MIVI SR + ИИ-редактор галереи |
| 0) SELinux probe | permissive на 20 с + сбор запретов (для глубокой диагностики) |

## 4. Лабораторные настройки: что включать и зачем

Открыть: Камера → Настройки → **Лабораторные настройки** (иногда «Дополнительные настройки»).

| Точное название настройки | Ключ | Что делает | Как ставить |
|---|---|---|---|
| **Включить мультилинзовый зум в видео** | `pref_camera_video_sat_enable_title` | бесшовный переход между линзами 0.5x↔1x↔3.2x↔5x во время записи | **ВКЛ** |
| **Принудительно включить мультилинзовый зум видео в любом качестве** | `pref_camera_video_sat60fps_enable_title` | тот же зум, но и в 4K/60 и других качествах; подпись «Может не поддерживаться вашим устройством» | **ВКЛ** (если камера не сбоит) |
| **Выключить линзу SAT** | `pref_telefix` | отключает SAT-линзу как «лечение» сбоев; при этом режимы с несколькими объективами теряют бесшовность | **ВЫКЛ** |
| **Ограничить многократное увеличение видео при включенном EIS** | `pref_limit_video_sat` | режет мультилинзовый зум при работающей стабилизации | **ВЫКЛ**, если хотите плавность со стабилизацией |
| **Включить исправление тройной камеры** | `pref_sat3fix` (подпись: «Изменяет идентификатор камеры на 120…») | костыль для некоторых прошивок | **ВЫКЛ** (на xiaomi.eu не нужен) |
| **Включить Отслеживание объектов в режиме видео** | `pref_autozoom_title` | авто-слежение за объектом при записи | по желанию |
| **Установить максимальное увеличение для режимов фотосъемки** | `pref_setzoom` | потолок зума в фото | 5–10x (в тесте стояло 5) |
| **Включить больше вариантов зума** | `pref_morezoom` | дополнительные шаги зума в интерфейсе | по желанию |
| **Включить параллельную обработку** | `pref_camera_parallel_process_enable_title` | фоновая обработка кадра (быстрее повторные снимки) | **ВКЛ** |
| **Принудительно включить HDR для видео** | `pref_videoHDR` | HDR в видео | по желанию |
| **Принудительно включить видео в ночном режиме** | `pref_night_video` | ночной алгоритм в видео | по желанию |
| **Включить качество 24 кадров в секунду в режиме видео** | `pref_24fps` | открывает 24 fps (нужно для 8K24/кино) | **ВКЛ** для 8K |
| **Включить поддержку 4K видео** | `pref_4k` | 4K-запись | **ВКЛ** |
| **Включить полную яркость при использовании камеры** | `pref_brightness` | экран не гаснет в камере | по желанию |
| **Принудительно включить фильтры мастера видео** | `pref_video_filters` | Leica-фильтры в видео | по желанию |
| **Показывать рамку лица в режиме видео** | `pref_camera_video_show_faceview_title` | рамка лица | по желанию |
| **Включить AI для фронтальной камеры** | `pref_frontAI` | ИИ на фронталке | по желанию |

Мастер-переключатели «ИИ» в интерфейсе камеры: **«AI камера»** (`pref_camera_ai_scene_title`) и в видео — `pref_camera_video_ai_scene_title`. Это распознавание сцен на устройстве; в облако ничего не уходит.

## 5. Что даёт ИИ-пак v6.6 (и как проверить)

Всё локально: **Snapdragon 8 Gen 2 + Hexagon DSP**, облако выключено (`cloud.*=0`).

| Компонент | Свойства | Что даёт | Как проверить |
|---|---|---|---|
| **AISP** | `persist.vendor.camera.aisp.enable=1`, `ro.vendor.camera.aisp=1`, `vendor.camera.aisp=1`, `aisp.setting=1` | ИИ-обработка кадра на NPU: тональность, детализация | фото в сложном свете; в логе `applyAiASDEnable:true` |
| **AINR** | `persist.vendor.camera.sensor.ainr=1` | нейросетевое шумоподавление | снимок в сумерках: меньше шума |
| **CyberFocus 2.0** | `persist.vendor.camera.cyberfocus.enable=1` | удержание фокуса на движущемся объекте | наведи на движущийся объект, фокус не «плавает» |
| **MIVI Super Resolution** | `persist.vendor.camera.mivi.super_resolution=1` | апскейл/детализация на устройстве | детали на 50 Мп кадре |
| **AI-сцена (ASD)** | `ai.enable=1`, `ai_scene=1`, `asd.enable=1`, `mialgo.asd=1` | распознавание сцены и подстройка | в логе `parseNonSemanticScene -> [...]` |
| **AI-коуч / режиссёр** | `persist.sys.camera.ai_coach.enable=1`, `persist.vendor.camera.ai.director=1` | подсказки по кадру, режим режиссёра | Настройки → соответствующие пункты |
| **ИИ-редактор галереи** | `persist.sys.miui.gallery.ai_editor=1` | пометка «HyperAI» в галерее: ластик, расширение кадра | Галерея → Изменить → AI-инструменты (см. ограничение в п.7) |

**Отключить весь ИИ-пак:** Action → **10) Toggle LOCAL AI pack** → перезагрузка.  
Когда отключать стоит: если ИИ даёт тормоз на затворе или холодный/синеватый оттенок. Это ожидаемый компромисс: ИИ-обработка точнее, но медленнее.

## 6. Функции камеры, которые теперь доступны

**Фото**
- Полное разрешение **50 Мп (8192×6144)** — конверт размеров; проверка: «Сведения» фото.
- Ручная диафрагма **f/1.9 ↔ f/4.0** (физическая), Stepless-апертура.
- **Leica Authentic / Vibrant / Monochrome**, водяной знак Leica и произвольный.
- **Режим «Уличная фотография» (Street, Fastshot)** — гиперфокальная шкала.
- **Портрет**: студийный свет версии 2, контровой/передний свет, бьютификация, «мягкий свет».
- Режимы: **Super Moon** (луна), **Super Macro** (макро), **Документы**, **Ночной**, **Pro/RAW (DNG)**, **Ultra RAW**.
- Фокусные 23 / 28 / 35 мм на основном модуле (переключатель фокусных).

**Видео**
- **Бесшовный мультилинзовый зум 0.5x–5x** (и до 15x по сплайну) во время записи.
- **8K 24/30**, **4K 60**, **4K 120** (заявлено флагами), **Dolby Vision** (файлы `*_DOLBY.mp4`), 1080p/720p.
- **LOG-видео**, **Director Mode**, **Cinematic**, **Dual Video** (две камеры), аудиозум, 3D-звук, подавление ветра.
- Снимок во время записи (`support_recording_snap`).

**Сервисное**
- Логи в `/sdcard/Download/CameraMod_Logs` (маркер `BUILD: v6.6-EU-A16`).
- Bootloop saver, быстрый откат, Action-меню.

## 7. Ограничения — честно

1. **`com.miui.extraphoto` в этой прошивке нет.** Без него ИИ-редактор галереи (ластик, расширение кадра) может не появиться, даже при включённых свойствах. Решение: доустановить MiuiExtraPhoto из стоковой сборки HyperOS 3 либо пользоваться галереей xiaomi.eu «как есть».
2. **8K/4K120 зависят от HAL прошивки.** Флаги и сессии камера создаёт (в логе видно `recordSurface … 7680x4320`), но реальная запись — как решит vendor-слой. Если режим есть в меню, но файл не пишется — это ограничение ROM, а не модуля.
3. **Код 6.8 не переносится.** Всё, что живёт в самом приложении 6.8 (например, «Picture Style» как движок), в payload 5.0 включить нельзя — перенесены только свойства, флаги и конфиги.
4. **ИИ и скорость** — обратная связь: AISP/AINR дают лучший кадр, но затвор медленнее. Если не нравится — Action → 10).
5. **Синева на фото** — если появится, переключить Action → **8) Toggle AISP/ASD** (в fix2 это лечило оттенок).
6. **Мелкие фото (1.6 Мп)** — проверять Action → **9)** (конверт) и **2)** (MIVI-кэш), затем перезагрузка.

## 8. Готовые сценарии

| Хочу | Что сделать |
|---|---|
| Максимум качества фото | Action: LOCAL AI ON, AISP/ASD ON, envelope ON; Лаборатория: HDR/DCG не трогать |
| Быстро и нейтрально | Action → **8)** (AISP/ASD OFF); при тормозах ещё **10)** (LOCAL AI OFF) |
| Плавный зум в видео | Лаборатория: «Включить мультилинзовый зум в видео» ВКЛ, «Принудительно…» ВКЛ, «Выключить линзу SAT» ВЫКЛ, «Ограничить…при EIS» ВЫКЛ; запись 4K30 |
| 50 Мп всегда | Action → **9)** (envelope ON); Лаборатория: «Включить поддержку 4K» ВКЛ для видео, зум-потолок 5–10x |
| Кино 24p / 8K | Лаборатория: «Включить качество 24 кадров в секунду» ВКЛ → в режиме видео выбрать 8K |
| Разобраться, что сломалось | собрать `/sdcard/Download/CameraMod_Logs` и прислать архив |

## 9. Диагностика: симптом → причина → действие

| Симптом | Вероятная причина | Действие |
|---|---|---|
| Фото 1.6 Мп | не применился конверт размеров / нет MIVI-кэша | Action → 9), затем 2), перезагрузка |
| Затвор «висит» 30–40 с | ИИ-конвейер ждёт сцену | Action → 8) (AISP/ASD OFF) |
| Фото с синим оттенком | ИИ-цветокоррекция под чужой сенсор | Action → 8) |
| Видео пишется, но зум резкий | SAT-линза отключена или зум ограничен EIS | Лаборатория: «Выключить линзу SAT» ВЫКЛ, «Ограничить…при EIS» ВЫКЛ |
| Иконка камеры пропала | конфликт оверлеев/пакетов | Action → 5), перезагрузка, прислать логи |
| «close failed: EPERM» в логах | камера не могла перезаписать свой конфиг | исправлено в v6.6 (права `media_rw`); если повторится — прислать логи |
| Камера ушла в bootloop | аварийный случай | модуль сам отключится после 2 загрузок; флаг `/sdcard/disable_camera` |

## 10. Что прислать для разбора

1. Архив `/sdcard/Download/CameraMod_Logs` целиком (там `00_SUMMARY.txt` с маркером сборки).
2. Краткое описание: что делал, что ожидал, что получилось.
3. Для видео-жалоб — **исходный** файл с телефона (не сжатый Telegram), чтобы можно было посчитать кадры перехода.
