# Упаковка модуля камеры

Модуль не установится, если в архиве есть хотя бы один скрипт с окончаниями
строк Windows. Это ломает установку полностью, а выглядит как проблема
совместимости с Android. Проверка окончаний — **первый и обязательный шаг**.

## Структура модуля

```
module/
├── module.prop                                    # обязателен
├── customize.sh                                   # обязателен, LF
├── service.sh                                     # LF
├── post-fs-data.sh                                # LF
├── system.prop                                    # LF
├── system/priv-app/MiuiCamera/
│   ├── .replace                                   # маркер подмены
│   ├── MiuiCamera.apk
│   └── lib/arm64/*.so                             # 49 нативных библиотек
├── system/odm/etc/camera/                         # калибровки
├── configs/                                       # .agc пресеты для AGC
└── META-INF/com/google/android/
    ├── update-binary
    └── updater-script
```

## Порядок сборки

### 1. Скрипты пишутся и сохраняются в LF

Любой редактор на Windows по умолчанию ставит CRLF. После правки скрипта
окончания надо привести к LF **до** упаковки.

Правило для Python: открывать файлы с `newline='\n'`.

```python
with open(path, 'w', encoding='utf-8', newline='\n') as f:
    f.write(content)
```

Не `'w'` без `newline` — тогда на Windows добавится `\r`.

### 2. Упаковка

Использовать `scripts/package_module.py` — он сохраняет LF и кладёт записи с
прямыми слэшами.

### 3. Проверка — обязательна

Запустить `scripts/verify_module.ps1`, передав путь к архиву:

```powershell
& 'C:\Mi_Master_Camera_Combo\.agents\skills\package-magisk-module\scripts\verify_module.ps1' `
  -Zip 'C:\Mi_Master_Camera_Combo\github_sync\releases\Mi15U_Master_Camera_Combo_5_v6.4_A16_Final.zip'
```

Скрипт проверяет:

| Проверка | Что ищет |
|---|---|
| Окончания строк | CRLF в любом `.sh` — **блокирующая ошибка** |
| Разделители путей | обратные `\` в именах записей архива |
| Обязательные файлы | `module.prop`, `customize.sh` |
| Версия | `version` и `versionCode` в `module.prop` |
| Камера | наличие `MiuiCamera.apk` и её версия |
| Размер | архив не нулевой |

## Отдельно про версию

`version` в `module.prop` и имя файла должны совпадать. Уже была ситуация,
когда файл назывался `v6.4`, а внутри стояло `v6.1` с тем же `versionCode` —
Magisk показывал тестерам старую версию, и обновление не применялось.

**`versionCode` обязан увеличиваться при каждом релизе.** Формат в проекте —
дата и порядковый номер: `2026093008`.

## Что проверить перед отправкой тестерам

1. `verify_module.ps1` прошёл без блокирующих ошибок
2. База камеры соответствует устройству — см. навык `verify-camera-base`
3. `ro.product.device` **не подменяется** в скриптах
4. Число нативных библиотек совпадает с эталоном (49 для полной сборки)
5. Инструкция для тестера написана по правилам проекта

## Если модуль не ставится у тестера

Первым делом запросить лог установки Magisk и посмотреть на ошибки.

| Что в логе | Причина |
|---|---|
| `syntax error: unexpected word (expecting "do")` | CRLF в скрипте |
| `line N: { : not found` | CRLF в скрипте |
| Мусорные пути вида `configsaurora.json` | CRLF ломает `\`-переносы |
| `This module is not for your device` | проверка железа в `customize.sh` |
| `Installation failed` без деталей | смотреть выше по логу |

Ошибка `syntax error` означает, что **до подмены камеры дело не дошло** — модуль
не установлен вообще. Ни сенсоры, ни MIVI, ни кодовые имена тут ни при чём.
