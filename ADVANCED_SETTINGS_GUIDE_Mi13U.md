# Руководство по «Расширенным настройкам» (Advanced Settings) для Xiaomi 13 Ultra (ishtar)
**Версия камеры:** Leica Master Edition by `borndead`  
**Целевое устройство:** Xiaomi 13 Ultra (Snapdragon 8 Gen 2, Sony IMX989 1" + 3x Sony IMX858 50Мп)

---

## Введение

Раздел **«Расширенные настройки»** (Advanced Settings) управляет прямой передачей параметров в DSP и сигнальный процессор обработки изображений Qualcomm Spectra ISP. Настройка этих параметров позволяет убрать эффект «смартфонной обработки» и раскрыть физическую оптику Leica Summicron.

---

## Таблица настроек и рекомендации

| Параметр в меню | Доступные значения | Рекомендация для 13 Ultra | Обоснование и влияние на снимок |
|-----------------|-------------------|:-------------------------:|---------------------------------|
| **Насыщенность (Saturation)** | Низкая / По умолчанию / Высокая | **По умолчанию** | Фирменные цветовые профили Leica Authentic и Leica Vibrant уже содержат калиброванную цветовую матрицу. Завышение параметра приводит к перенасыщению и постеризации в ярких участках. |
| **Контраст (Contrast)** | Низкий / По умолчанию / Высокий | **По умолчанию** | Leica Authentic использует глубокие тона и естественное затемнение по краям (виньетирование). По умолчанию контраст сбалансирован идеально. |
| **Четкость / Резкость (Sharpness)** | Низкая / По умолчанию / Высокая | **Низкая (или По умолчанию)** 🏆 | **Режим «Чистая оптика» (Pure Optics)!** У сенсора Sony IMX989 и объективов Summicron выдающаяся оптическая резкость. Снижение программного шарпинга («Низкая») убирает белые микро-ореолы вокруг веток и текста, делая картинку мягкой и «пленочной», как на полнокадровой камере Leica M/Q. |
| **Устранение шума (Noise Reduction)** | Низкое / По умолчанию / Высокое | **Низкое (или По умолчанию)** | Агрессивное шумоподавление превращает мелкие детали (траву, листву, поры кожи) в акварель. Огромная площадь 1-дюймового сенсора улавливает достаточно света, поэтому благородный мелкий шум смотрится естественно. |
| **Устранение искажений (Distortion Correction)** | Вкл / Выкл | **ВКЛ** | Корректирует бочкообразную дисторсию на 12mm сверхширокоугольном модуле (0.5x). Линии зданий и горизонт остаются прямыми. |
| **Подавление хроматических аберраций (Depurple)** | Вкл / Выкл | **ВКЛ** | Устраняет фиолетовые и зеленоватые каймы на контрастных границах (ветки деревьев на фоне белого неба, металлические блики). |
| **Кривая тонопередачи (Tone Curve)** | DEFAULT / Rec. 709 | **DEFAULT** | `DEFAULT` использует фирменный S-образный тональный профиль Leica с плавным спадом в светах. `Rec. 709` переводит кривую в стандарт телевизионного вещания с более жестким отсечением в полутонах. |
