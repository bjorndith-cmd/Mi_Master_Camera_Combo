### Как применить пресет в AGC:
1. Скачайте нужный `.agc` файл для вашей модели (прямое скачивание по ссылкам выше).
2. Скопируйте его во внутреннюю память смартфона по пути:
   * Для AGC 9.x: `/Download/AGC.9.6/configs/` (или `/Download/AGC.9.2/configs/`)
   * Для AGC 8.x: `/AGC/configs/`
   *(Если папки нет — создайте её или сохраните любой тестовый конфиг в настройках AGC, папка создастся сама).*
3. Откройте **AGC**.
4. **Дважды коснитесь (Double Tap)** тёмного пустого пространства между кнопкой спуска затвора и галереей.
5. В появившемся окне выберите скачанный `.agc` файл и нажмите **«Load» (Загрузить)**.
6. Приложение перезапустит видоискатель с готовыми настройками. Снимайте в режиме **HDR+ Enhanced**!
